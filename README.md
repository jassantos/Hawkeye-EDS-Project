Program Design 
The Program Design section outlines the overall structure and behavior of the Hawkeye Customer Service Portal’s user interface. It describes how each UI component is organized, how pages interact, and what technologies are used to implement the front-end system. The application is built entirely using HTML, CSS, and JavaScript, forming the core of the view layer. These technologies collectively define the page structure, styling, and interactivity across modules such as Login, Dashboard, Messaging, Customer Support, and Settings.
The design follows a modular and reusable component structure, where each page is designed as a self-contained interface connected through consistent navigation elements. JavaScript handles form validation, simulated OTP verification, and user interaction flow.
		
Functional Description
Each component of the view layer represents a key feature described in the PRS:
•	Login Page: Accepts user credentials and simulates OTP verification.
•	Dashboard Page: Displays ticket statistics and activity charts.
•	Messages Page: Allows users to read and send messages tied to tickets.
•	Customer Support Page: Provides forms to create or review tickets.
•	Personnel Page: Displays personnel list and update options.
•	Settings Page: Lets users modify their displayed profile and preferences.
These pages work together using a shared navigation bar and consistent interface design.
